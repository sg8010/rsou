# rsou - 本地文档全文搜索工具

rsou 是一款专为个人打造的本地文档搜索工具。你可以把电脑里的各类文档（Word、Excel、PPT、PDF、纯文本和电子书）加入资料库，随后即可直接搜索正文和标题。

所有处理均在本地电脑完成，无需联网，不上传任何数据，安心保护个人隐私与商业机密。

---

## 核心特性

- **格式支持全面**：支持日常办公常见的 Word、Excel、PPT、PDF、纯文本以及 EPUB 电子书。
- **本地离线运行**：所有文档分析和搜索均在本机进行，不依赖外部网络，不上传文件。
- **快速全文搜索**：不仅搜索文件名，更能深入搜索文档内部正文；多个关键词跨段落也能准确匹配。
- **即时预览与高亮定位**：搜索结果按文档归类展示。点击左侧的匹配片段，右侧窗口直接显示文档原文，并高亮定位到对应位置。
- **智能更新省时省力**：添加文件夹后，软件能自动识别文件变动；未变动的文件直接跳过，修改过的文件自动更新。
- **安全不影响原文件**：软件内的所有移除、清空操作仅管理搜索记录，绝不会修改或删除电脑中的原始文件。

## 快速上手

使用 rsou 只需要简单的三步：

1. **添加文档（资料库页面）**
   点击「添加文件」或「添加文件夹」（支持自动扫描所有子文件夹）。
   - 软件会在后台自动解析并建立搜索记录，可实时查看处理进度。
   - 如果遇到加密文件或无法读取的文件，可以在「显示失败清单」中查看具体原因，支持单独重试或移除。

2. **搜索与查看（检索页面）**
   在搜索框中输入关键词后按回车：
   - **查看摘要**：搜索结果按文档分组，自动展示包含关键词的上下文片段。
   - **定位原文**：点击任意一条片段，右侧窗口会直接展示文档原文并自动跳转到高亮位置。
   - **快速筛选**：可按文件类型、所属目录或修改时间（最近 7 天 / 30 天 / 1 年）缩小查找范围。

3. **管理与维护（设置页面）**
   在设置页面中，可以查看已收录文档数量及占用的空间大小：
   - 支持数据完整性检查、重新建立索引以及数据库清理优化。
   - 可按需调整单文件大小上限（默认处理 100 MB 以内的文档）。

## 搜索技巧与语法

日常查找直接输入关键词即可。如果需要更精准的结果，可以使用以下常用搜索技巧：

| 搜索写法 | 规则说明 | 示例 |
|---|---|---|
| **空格隔开** | 同时包含所有词 | `项目 总结`（两个词都包含） |
| **减号排除** | 包含前面的词，但不包含减号后的词 | `合同 -草稿`（查找合同，排除草稿） |
| **OR 或者** | 包含其中任意一个词即可 | `方案 OR 计划` |
| **英文双引号** | 精确匹配一整句或短语（含空格） | `"技术规范 2026"` |
| **title: 前缀** | 只在文件名或标题中查找 | `title:财务报表` |
| **content: 前缀** | 只在文档正文中查找 | `content:会议纪要` |
| **小括号组合** | 组合复杂条件 | `(初稿 评审) OR 终稿` |

> **提示**：
> - **搜索模式**：默认为「精确模式」，按输入内容直接查找；切换到「宽松模式」后，软件会自动拆分词语，即便关键词之间夹杂了其他文字也能找出。
> - 暂不支持 `*` 通配符搜索，直接输入要查找的文字即可。

## 下载与运行

### Windows 系统 (Windows 7 及更高版本)
- 提供 64 位与 32 位版本。
- **免安装绿色版**：下载解压后直接双击可执行文件（`.exe`）即可使用。

### Linux 系统 (统信 UOS / 麒麟系统 / Ubuntu / Debian 等)
目前提供针对 ARM64 架构（常见国产桌面电脑、树莓派等）的运行程序：

1. **Debian 软件包安装（推荐）**
   双击下载的 `.deb` 安装包进行安装，或在终端执行：
   ```bash
   sudo dpkg -i rsou_版本_arm64.deb
   # 或者: sudo apt install ./rsou_版本_arm64.deb
   ```
   安装完成后可在系统的应用程序菜单中找到并启动。

2. **单文件直接运行**
   如果下载的是单独的可执行文件，赋予执行权限后即可直接启动：
   ```bash
   chmod +x rsou-linux-arm64
   ./rsou-linux-arm64
   ```

## 常见问题

**Q: 为什么有些扫描版 PDF 搜索不到内容？**
> 答：扫描件本质上是图片，文件内部没有可提取的文字信息。当前版本暂未集成图片文字识别（OCR）功能。如果文档由扫描图片生成，暂时无法直接搜索其正文。

**Q: 在软件里移除文件或清空资料库，会删除电脑里的原文件吗？**
> 答：绝对不会。软件内的所有移除、删除操作仅清除软件内部的搜索索引记录，绝不会改动或删除您硬盘上的任何原始文件。

**Q: 搜索数据保存在哪里？**
> 答：所有数据统一保存在本机的单个数据库文件中：
> - Windows: `%LOCALAPPDATA%\rsou`
> - Linux: `~/.local/share/rsou`（或 `$XDG_DATA_HOME/rsou`）
>
> 在软件的「设置」页面可以直接查看路径并一键打开所在目录。日常使用中通过软件界面管理即可，请勿手动编辑该数据文件。

**Q: Linux 桌面下点击后无法打开界面怎么办？**
> 答：软件启动需要系统的图形显示与 OpenGL 基础运行库支持。如果点击后没有反应，可以查看日志文件 `~/.cache/rsou/startup.log`，将日志内容反馈协助排查。（注意：当前暂不支持纯 Wayland 桌面，需要系统开启 XWayland 兼容支持）。

**Q: 想要导入大量文档，怎样操作最方便？**
> 答：添加单个文件时每次选择一个。若有大量文件，建议将它们整理在文件夹中，直接点击「添加文件夹」，软件会自动扫描并收录该文件夹及其子文件夹下的所有支持文件。

### 从源码构建

环境要求：Rust stable（2024 edition）。

```bash
# 编译 Linux 本机版本
cargo build --release
# 构建产物位于 target/release/rsou
```

#### Windows 交叉编译（在 Linux 环境下）
支持在 Linux 环境下交叉编译生成兼容 Windows 7 及以上系统的独立程序：

```bash
# 安装 MinGW 交叉编译工具
sudo apt install -y \
  gcc-mingw-w64-x86-64 binutils-mingw-w64-x86-64 \
  gcc-mingw-w64-i686 binutils-mingw-w64-i686

# 执行构建脚本（同时构建 x64 与 x86 版本并进行系统兼容性审计）
./scripts/build-win.sh
```

### 运行测试

```bash
cargo test -p rsou
```

### 技术架构

| 模块 | 技术选型 | 说明 |
|---|---|---|
| 界面框架 | egui / eframe | 轻量即时模式 GUI，内存占用低，自带虚拟化表格 |
| 文档解析 | anydoc + encoding_rs | 纯 Rust 实现的 Office/PDF/EPUB 转文本，文本自动探测编码 |
| 全文检索 | SQLite FTS5 + 自定义分词器 | 内嵌 SQLite，零额外运行依赖，支持高效中文搜索 |
| 中文分词 | jieba-rs | 用于宽松检索模式的中文分词 |
| 多线程加速 | rayon | 多核并行解析，大幅提升批量文件导入速度 |
